# BookNook Project Report

## Objective
BookNook is a responsive online bookstore and stationery e-commerce interface designed to simulate a real-world shopping experience. The project focuses on clean navigation, book discovery, product details, cart management and a simulated checkout.

## Technologies
HTML5 was used for semantic page structure, CSS3 for the responsive scholarly visual design, and vanilla JavaScript for product data, filtering, cart operations, simulated authentication and checkout. localStorage is used to preserve cart data between pages. No database is required.

## Key Features
- Home page with hero banner, categories and bestsellers
- Product listing with search, filters and sorting
- Product detail with author, publisher, ISBN, price and rating
- Shopping cart with quantity changes and total calculation
- Checkout with shipping information and payment method selection
- Simulated login/register and user account
- About and contact pages
- Responsive desktop/tablet/mobile layouts

## Learning Outcomes
The project demonstrates practical frontend development, reusable JavaScript functions, DOM manipulation, localStorage, responsive CSS Grid/Flexbox, form validation and multi-page website navigation.

## Challenges
The main challenges were keeping cart state consistent across multiple pages, building reusable product cards, creating filter combinations and maintaining a responsive layout across screen sizes. These were addressed with shared JavaScript data, localStorage and CSS media queries.
