# BookNook — Books & Stationery

Frontend-only e-commerce project for the Data Alcott Systems Web Development Internship task **WD-EC-005**.

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- JavaScript arrays/objects + localStorage (no database)
- Google Fonts

## Features
- Responsive home page
- Category browsing
- Product listing with search, category, language, price and rating filters
- Sorting
- Product detail pages with book metadata
- Cart with quantity adjustment and price calculation
- Checkout with shipping form and simulated payment methods
- Simulated login/register
- Account page
- Wishlist/account placeholders
- About and Contact pages
- Order confirmation flow
- Mobile responsive layout

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Suggested GitHub Pages deployment
1. Create a public GitHub repository.
2. Upload all project files.
3. Go to Settings → Pages.
4. Deploy from the `main` branch, root folder.
5. Open the generated Pages URL.

No real payment, authentication, or database is used because this is a frontend-only internship project.
